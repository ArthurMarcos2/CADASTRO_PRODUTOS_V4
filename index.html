O que é Bootstrap?

Bootstrap é uma biblioteca de código aberto que facilita a criação de interfaces para sites e aplicações.

Ele oferece componentes prontos, como botões, formulários, tabelas, menus e janelas modais, além de recursos para adaptar páginas a diferentes tamanhos de tela.

Com o Bootstrap, os desenvolvedores conseguem criar interfaces modernas e responsivas com mais facilidade.
